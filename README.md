# Весёлый алфавит

Интерактивная мини-игра для детей 4–5 лет: изучение русских букв А, Б, В, Г, Д.

## Играть онлайн

После деплоя игра доступна по адресу:

**https://shimnadezhda1-dev.github.io/Game/**

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`

## Сборка

```bash
npm run build
npm run preview
```

## GitHub Pages

При каждом push в ветку `main` игра автоматически публикуется через GitHub Actions.

В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
